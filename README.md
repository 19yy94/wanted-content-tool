# 합격은 확률이다 · 콘텐츠 템플릿

직무를 선택하면 포지션 추천 · 이력서 키워드 · 면접 예상 질문 세 콘텐츠가 바뀌고, 이미지(1080×1350)와 영상으로 저장할 수 있습니다.
