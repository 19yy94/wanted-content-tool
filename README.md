# 합격은 확률이다 · 콘텐츠 템플릿

원티드 '합격은 확률이다' 캠페인 1·2·3편(포지션 추천 · 이력서 키워드 · 면접 질문) 콘텐츠를 직무별로 만들고 이미지·영상으로 저장하는 툴.

## 실행
정적 파일만 있어서 서버 없이 바로 올릴 수 있어요. `index.html`이 메인 툴이에요.

- **GitHub Pages:** 이 폴더를 저장소에 올리고 Settings → Pages → Branch(main, /root) 선택
- **로컬 확인:** 폴더에서 `python3 -m http.server` 실행 후 http://localhost:8000
  (파일을 더블클릭으로 열면 폰트·모델을 못 불러와요)

## 구성
- `index.html` — 콘텐츠 템플릿 (1·2·3편 탭)
- `ep1/` `ep2/` `ep3/` — 각 편 원본 페이지 (단독으로도 열림)
- `fonts/` — 타이틀 폰트, 3편 영상용 폰트 서브셋 도구

## 참고
- 영상 저장은 최신 PC 크롬을 권장해요. (아이폰·앱 내 브라우저는 영상 인코딩이 제한될 수 있어요)
- 1편 3D 인물은 three.js를 jsDelivr CDN에서 불러와서 인터넷 연결이 필요해요.
