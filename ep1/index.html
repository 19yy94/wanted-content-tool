현재 모델 조정
크기는 머리 꼭대기를 기준으로 커지고 줄어요. 일시정지 → 칩으로 모델 선택 → 가이드 선에 머리/어깨를 맞추세요. 값은 파일 이름별로 저장돼요.
포즈별로 따로 내보낸 GLB 파일을 올리면 돼요(Mixamo, Blender 등). 모델 사이에서는 칸이 뒤집히는 웨이브로 전환돼요.
이 높이 아래는 모든 모델에서 잘라내요. 상반신 길이를 통일할 때 써요.
화면 구성 (텍스트 자리)
포즈가 멈출 때마다 실제로 잰 값이에요. 격자 · 명암 · 각도를 바꾸면 달라져요.
0° = 정면, ±35° 정도가 대각선 앞모습이에요. "계속 회전" 방식에서 적용돼요.
포즈가 완성되면 회전이 잠시 멈췄다가 다시 돌아요. 유지 시간 안에 끝나도록 자동으로 맞춰져요.
돌 때는 그레이 3단계, 멈추는 순간 밝은 쪽이 포인트 색으로 뒤집혀요. 멈춘 순간 포인트 색 비율은 위 측정값에 표시돼요.

합격 카드 (멈출 때 등장)
포즈마다 위치를 다르게 하려면: 위 포즈 버튼으로 포즈를 고르고, '계속 보이기'를 켠 뒤 캔버스에서 카드를 끌어 옮기세요. 위치 칸을 비우면 공통 위치를 따라가요.
숫자는 멈춘 순간 흰 원 비율로 자동 계산돼요. 포즈별 % 칸에 값을 넣으면 그 값이 우선이에요. 로고 칸을 눌러 이미지를 올리세요.
밝은 쪽 원은 앞면(밝은 톤), 그림자 쪽 원은 뒷면(진한 톤)이 보여요. 경계를 넘을 때 원이 뒤집혀요.
올릴수록 밝은 단계(흰 동전)가 많아져요. 멈춤 순간 비율도 같이 올라가요.
